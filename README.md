# Naruto Shinobi Cards 0.7

Распакуй архив полностью. Запуск: start.py (Python 3) или index.html. Для GitHub Pages загрузи содержимое архива в корень репозитория.

Обновление: перед заменой файлов скачай сохранение в профиле. При смене папки или адреса импортируй его в новой версии.

Новое: главный баннер перед наградами; сортировка 30 паков по цене; улучшение весов редкостей с ценой и уровнем; четыре анимированные рамки и четыре фона удостоверения; титулы за победы и паки; выбранный аватар в бою; цветовые роли в руке; кнопка «Фото сквада» скачивает PNG. Экспорт фото использует локальные изображения и надёжнее работает через start.py / сайт, чем file://.

Шансы каждого пака указаны в магазине отдельно для первых четырёх и пятой карты; они учитывают доступные в наборе редкости. Сохраняется гарантия Legendary+ на 50-й карте в подходящем пуле. Игра против локального ИИ, общий серверный рейтинг отсутствует.
